## Kết quả đạt được tuần 8

- Cấu hình thành công **Amazon API Gateway** để cung cấp API HTTPS công khai cho ứng dụng frontend.
- Thiết lập thành công **API Gateway VPC Link**, tạo kết nối an toàn giữa API Gateway và dịch vụ backend đang chạy trong VPC.
- Kiểm tra và xác nhận luồng dữ liệu hoạt động ổn định, đảm bảo frontend có thể gọi thành công các API của backend nội bộ thông qua **Amazon API Gateway** và **VPC Link**.
- Nâng cao hiểu biết về cách xây dựng và triển khai kiến trúc API an toàn trên AWS, tạo nền tảng cho việc phát triển và mở rộng dự án **AI Recipe Finder**.
